# Planification de sprint — 21 mai 2026

## Ce qui a avancé dans les 3 dernières semaines

### La Vitrine démocratique (site web)

- **Refonte technologique majeure** — Le site a été migré vers une architecture moderne (Next.js), ce qui le rend plus maintenable et prêt à grandir.
- **Nouveau module : Parole en chambre** — Une nouvelle section affiche ce que les décideurs politiques disent à l'Assemblée nationale, branchée sur des données réelles.
- **Système de signalement intégré** — Les utilisateurs peuvent maintenant signaler des problèmes directement dans le site (clic droit), avec possibilité de joindre une capture d'écran.
- **Infrastructure de déploiement automatisée** — Les données se rafraîchissent et se déploient automatiquement sans intervention manuelle.
- **Améliorations visuelles** — Meilleure présentation mobile, corrections d'affichage sur les unes et les enjeux, images générées automatiquement.
- **Page d'abonnement** — Mise en place d'une page "en construction".

### Raffineurs de données (aws-refiners)

- **Nouveau raffineur : Parole en chambre** — Un nouveau module extrait et analyse les interventions des élus à l'Assemblée nationale du Québec.
- **Nouveau raffineur : Détection d'événements** — Un algorithme regroupe automatiquement les nouvelles par événements et mesure leur saillance dans le temps.
- **Étiquettes intelligentes sur les enjeux** — L'IA génère maintenant des libellés courts et contextuels pour chaque enjeu politique.
- **Stabilisation et corrections** — Plusieurs ajustements de fiabilité sur les modules existants (scores, clustering, compatibilité de données).
