# Caroussel · La Une des Unes

Espace réservé aux caroussels du module « La Une des Unes ».

Intention éditoriale :

- garder les reels courts pour les analyses statistiques seulement;
- utiliser les caroussels pour raconter une Une complète;
- inclure, selon les données disponibles, le score de saillance, l’évolution, la description de la Une et les médias qui en parlent.
